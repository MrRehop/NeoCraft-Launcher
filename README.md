# NeoCraft Launcher

NeoCraft is an open-source Android launcher project for Minecraft PE Patched, with the NeoMod modification system and planned offline/LAN support.

## Source snapshot

The current Stage 9 source snapshot is available in [`NeoCraft-NeoMod-Stage9-clean.zip`](./NeoCraft-NeoMod-Stage9-clean.zip). It contains the Gradle project under the `NeoCraft/` directory. Download and extract the archive to work with the Android project.

## Current status

- Stage 9 source snapshot uploaded.
- Android Gradle build workflow is included inside the archive at `NeoCraft/.github/workflows/android-apk.yml`.
- No APK build is claimed until GitHub Actions completes successfully.
- Offline/LAN multiplayer remains planned, not implemented.
